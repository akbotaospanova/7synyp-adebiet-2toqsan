# Bilim Hub · Қазақ әдебиеті · 7-сынып · 2-тоқсан

«Толғауы тоқсан қызыл тіл» бөлімі бойынша 16 сабаққа арналған интерактив сайт.

- 16 сабақ: топтық тапсырмалар, ЕББҚ, зияткерлік алаң, БЖБ №3, №4, ТЖБ, рефлексия
- Әр сабақта 6 интерактив ойын және ҚМЖ
- 3 баспаның оқулығы (Атамұра, Арман-ПВ, Мектеп): бет нөмірін басқанда бет ашылады
- Сөздікқор-бот
